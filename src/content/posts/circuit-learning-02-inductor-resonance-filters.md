# 第二课时：电感、谐振电路、LC、RC 滤波器

> 学习来源：`D:\Archive_afeng\硬件学习课件\第二课时-电感、谐振电路、LC、RC滤波器 (1).pptx`（24 页）  
> 本笔记将课件内容与本次对话中的提问合并整理。公式中的频率 `f` 单位为 Hz，角频率 `ω = 2πf`。

## 一、这节课讲了什么

课件的逻辑可以概括为：

1. 认识电感及其基本特性、分类和损耗；
2. 了解如何阅读电感规格书；
3. 理解 LC 储能交换与串、并联谐振；
4. 认识滤波器常用指标；
5. 学习 RC 高通/低通、LC 低通/高通/带通；
6. 重点理解：LC 滤波器不能只按理想 L、C 计算，负载会改变谐振峰和实际滤波效果。

## 二、电感的电气特性

### 1. 电感量与电流变化

电感的基本关系：

\[
v_L=L\frac{di_L}{dt}
\]

- 电感阻碍的是**电流的突变**，不是简单地“阻碍电流”。
- 电流变化越快（`di/dt` 越大），或电感量 `L` 越大，电感两端感应电压越大。
- 理想电感在直流稳态下 `di/dt = 0`，两端压降为 0，近似短路；实际电感仍有绕组直流电阻 DCR。

### 2. 对交流的阻抗

\[
X_L=\omega L=2\pi fL
\]

- 频率越高，电感感抗越大；电感量越大，感抗也越大。
- 理想电感中，电流相对电压**滞后 90°**。
- 电感将能量储存在磁场中：

\[
E_L=\frac{1}{2}LI^2
\]

### 3. 常见作用

- **开关电源储能与能量传递**：Buck、Boost 等 DC-DC 的核心元件。
- **滤波/扼流**：串在电源或信号路径中，阻碍高频电流变化。
- **限流和平滑电流**：降低纹波、抑制电流尖峰。
- **谐振与选频**：与电容构成 LC 谐振回路。
- **EMI 抑制**：磁珠、共模电感和扼流圈都属于相关应用。

### 4. 分类与实际非理想性

课件列出固定电感与可调电感；可调电感通常通过移动铁氧体磁芯改变电感量。

实际选型不能只看 `L`，还要看：

- **DCR（直流电阻）**：直流电流造成铜损和发热，近似为 `P = I² × DCR`；
- **ACR（交流电阻）**：由集肤效应等造成，频率升高时一般增大。ACR 是等效电阻，**不是感抗**；
- **磁芯损耗**：课件介绍磁滞损耗、涡流损耗和剩余损耗；
- **额定电流/饱和电流**：磁芯饱和后电感量下降，滤波和储能能力会明显变差；
- **自谐振频率（SRF）**：绕组寄生电容使电感在足够高的频率不再表现为理想电感；
- 封装、温升、容差以及工作频率范围。

## 三、电感与电容的区别

| 对比项 | 电感 L | 电容 C |
| --- | --- | --- |
| 储能形式 | 磁场 | 电场 |
| 基本关系 | `v = L·di/dt` | `i = C·dv/dt` |
| 抗拒的突变 | 电流突变 | 电压突变 |
| 直流稳态（理想） | 近似短路 | 近似开路 |
| 高频阻抗趋势 | 变大 | 变小 |
| 能量 | `E = 1/2·LI²` | `E = 1/2·CV²` |

可把电感理解为“电流的惯性”，把电容理解为“电压的缓冲”。

## 四、LC 谐振

电感与电容分别储存磁场能量、电场能量；在合适频率下，能量会在两者之间来回交换，形成电振荡。

谐振条件是总电抗为零：

\[
X_L+X_C=0
\]

若把电容电抗写成带符号的 `X_C=-1/(ωC)`，则有：

\[
\omega L=\frac{1}{\omega C}
\]

\[
f_0=\frac{1}{2\pi\sqrt{LC}}
\]

### 串联 LC

- 谐振时输入阻抗最小，回路电流最大；
- L、C 两端的电压可能远大于输入电压，称为电压放大/电压放大效应；
- 低于 `f₀` 时整体呈容性，高于 `f₀` 时整体呈感性。

### 并联 LC

- 谐振时输入阻抗最大，电源提供的电流最小；
- L、C 支路之间仍可能存在很大的循环电流；
- 常用于选频、阻抗变换和谐振槽等场合。

> 注意：课件第 12 页把第二个频率条件也写成了 `f < f₀`；这里应为 `f > f₀`。同时，“串联用于电压放大、并联用于电流放大”只能作为特定拓扑下的现象提示，不能替代上面的阻抗和电流结论。

## 五、滤波器的基本指标

课件在 LC 滤波器设计部分介绍了以下术语：

- **中心频率 `f₀`**：带通或带阻滤波器通带中心，常用 `f₀ ≈ (f₁ + f₂)/2` 作初步描述；
- **截止频率 `f_c`**：低通的通带右边界或高通的通带左边界，工程上常用相对 `-3 dB` 点定义；
- **带宽 `BW`**：`BW = f₂ - f₁`；
- **带内波动/纹波**：通带内插入损耗随频率变化的程度；
- **插入损耗**：加入滤波器后，目标频率处额外产生的信号衰减。

`-3 dB` 对应幅度约为原来的 `0.707` 倍，对应功率为原来的一半。

## 六、RC 滤波器

RC 滤波器由一个电阻和一个电容构成，是一阶滤波器。高通和低通的截止频率公式相同：

\[
f_c=\frac{1}{2\pi RC}
\]

### RC 低通

```text
输入 ── R ──┬── 输出
            │
            C
            │
           GND
```

- 低频：电容阻抗大，信号容易到达输出；
- 高频：电容阻抗小，高频被旁路到地；
- 结果：**低频通过，高频衰减**。

### RC 高通

```text
输入 ── C ──┬── 输出
            │
            R
            │
           GND
```

- 直流和低频：串联电容阻抗大，难以通过；
- 高频：电容阻抗小，信号容易到达输出；
- 结果：**高频通过，低频衰减**。

实际计算时，信号源内阻和后级输入阻抗会改变等效 `R`，因此截止频率可能偏离只用标称 R、C 算出的结果。

## 七、LC 滤波器

LC 滤波器比 RC 多一个储能元件，是二阶网络；理想情况下，阻带滚降可达到约 `40 dB/dec`，但也会带来谐振峰和振铃风险。

### 按功能的四类

| 类型 | 通过什么 | 抑制什么 |
| --- | --- | --- |
| 低通 | 低频/直流 | 高频 |
| 高通 | 高频 | 低频/直流 |
| 带通 | 某一频率范围 | 范围外频率 |
| 带阻（陷波） | 除某段频率外的信号 | 指定频率范围 |

课件第 22 页列出低通、高通、带通三类；带阻/陷波是常见的扩展分类。

### 常见低通结构

```text
输入 ── L ──┬── 输出
            │
            C
            │
           GND
```

- 低频时：串联 L 的阻抗低，C 不易把信号旁路；
- 高频时：L 阻碍信号继续传递，C 将高频旁路至地；
- 结果：低频通过，高频被衰减。

### 常见高通结构

```text
输入 ── C ──┬── 输出
            │
            L
            │
           GND
```

### 负载为什么重要

课件用 `L = 1 μH、C = 1 μF` 的理想低通例子说明：无损、无负载的 LC 在谐振点会出现理论无穷大的尖峰，因此并不是实际可直接使用的“完美低通”。

- 实际电感的 DCR、磁芯损耗和电容 ESR 都会提供损耗；
- 外部负载也会提供阻尼；
- 对课件第 24 页所画的并联负载，`R_L` 越低通常阻尼越强、Q 值越低，谐振尖峰和振铃越小；
- 但负载过低也会带来输出压降、功耗或滤波指标变化，不能只追求“低阻负载”。

因此，LC 设计至少要同时确认：源阻抗、负载阻抗、工作/开关频率、直流电流、L 的饱和电流与 DCR、C 的 ESR/耐压，以及是否需要额外阻尼网络。

## 八、本次对话提问回顾

### 1. 什么是电感的谐振？

谐振通常指 LC 网络的现象，不是理想电感单独“谐振”。当 `X_L + X_C = 0` 时，电感和电容发生能量交换，频率由 `f₀ = 1/(2π√LC)` 决定。

### 2. RC 高通与低通的区别？

低通是“串联 R、对地 C”，让低频通过；高通是“串联 C、对地 R”，隔断直流并让高频通过。两者截止频率均为 `1/(2πRC)`。

### 3. LC 滤波器是什么？

它用 L 的“高频阻抗更大”和 C 的“高频阻抗更小”实现选频。最常见的电源低通是串联 L、对地 C。

### 4. LC 滤波器一共有几种？

按滤波功能通常分低通、高通、带通、带阻四类；按结构又可分 L 型、T 型、π 型和更高阶梯形网络等。

### 5. 电感的电气特性和作用？

关键是阻碍电流突变、储存磁场能量、对高频呈较大阻抗；它用于 DC-DC 储能、滤波、EMI 抑制、限流和平滑电流、谐振选频。

### 6. 电感与电容有什么区别？

电感抗电流突变、存磁场能量；电容抗电压突变、存电场能量。直流稳态时，理想 L 近似短路，理想 C 近似开路。

## 九、复习抓手

1. 看到电感先问：电流变化有多快？DCR、饱和电流和工作频率够不够？
2. 看到 RC 先找输出节点：C 对地通常是低通；C 串联通常是高通。
3. 看到 LC 先判定：谐振频率在哪里？源阻抗与负载阻抗是多少？会不会有峰值和振铃？
4. 不要把理想元件仿真尖峰直接当成实物性能；必须把 ESR、DCR、磁芯损耗、寄生参数和 PCB 布局纳入判断。
