# 第三课时：无源滤波器基础（1）学习笔记

> 学习来源：`第三课时-无源滤波器基础(1).pptx`，共 10 页。
>
> 本笔记以课件内容为主线，并补充必要的电路直觉、公式推导、工程注意事项和练习。课件中的课堂手写标注较为简略，以下对无法确认的部分不作过度解读。

## 一、这节课要解决什么问题

无源滤波器只使用电阻、电容、电感等无源器件，不需要运算放大器或晶体管提供增益。它的基本任务是：

- 让目标频段的信号尽量通过；
- 让不需要的频段被衰减；
- 把传导干扰或辐射耦合进来的噪声限制在合适的位置；
- 在满足滤波的同时，控制功耗、压降、温升、振铃和器件体积。

本课时重点从四条线展开：

1. RL 滤波器的高通、低通原理；
2. RC 与 RL 在功耗和直流压降方面的差异；
3. T 型滤波器的结构特点；
4. 共模、差模干扰及对应的滤波元件。

后两部分已经从“信号选择”进入“电磁兼容（EMC）”视角：不仅要问“滤掉什么频率”，还要问“干扰以什么回路流动”。

## 二、先建立器件直觉：电阻、电感、电容

### 2.1 电阻：任何频率都阻碍，但会持续消耗功率

理想电阻的阻抗为：

\[
Z_R=R
\]

它与频率无关。电流通过电阻会产生功率损耗：

\[
P_R=I^2R=\frac{V^2}{R}
\]

因此，电阻很适合用来提供阻尼、限流和设定时间常数，但不适合在大电流电源路径中承担很大的压降。

### 2.2 电感：阻碍电流的快速变化

理想电感的阻抗为：

\[
Z_L=j\omega L=j2\pi fL
\]

频率越高，电感呈现的阻抗越大；频率为 0（直流）时，理想电感相当于短路。因此常用一句话概括：

> 电感“通直、阻交”，更准确地说是通低频、阻高频。

电感两端的电压关系为：

\[
v_L=L\frac{di}{dt}
\]

这说明电感反对的是电流的突然变化。电流想快速增加或快速减小时，电感会产生相应的反向电压。

真实电感还具有 DCR（直流电阻）、磁芯损耗、寄生电容和饱和电流。课件强调 RL 中的 DCR 通常是 mΩ 级，这也是它在电源滤波中可能比串联电阻更省直流功耗的原因。

### 2.3 电容：阻碍低频和直流，容易通过快速变化

理想电容的阻抗为：

\[
Z_C=\frac{1}{j\omega C}
\]

频率越高，阻抗越小；直流稳态时，理想电容相当于开路。常用直觉是：

> 电容“通交、阻直”，更准确地说是通高频、阻低频。

电容电流关系为：

\[
i_C=C\frac{dv}{dt}
\]

电压变化越快，电容越容易吸收或提供电流，因此常被放在电源与地之间旁路高频噪声。

真实电容还具有 ESR、ESL 和漏电流。高频时，ESL 会使电容不再继续表现为理想电容，可能出现自谐振。

## 三、RL 滤波器：用分压理解高通和低通

RL 滤波器通常由串联的 R、L 构成，输出取在其中一个元件两端。关键不是“元件放在哪里”这一句话，而是：

> 输出取在哪个元件上，决定哪个元件的阻抗变化会变成输出的频率选择性。

### 3.1 RL 高通：输出取电感两端

假设 R 与 L 串联，输入为 \(V_{in}\)，输出取电感两端：

\[
H_{HP}(j\omega)=\frac{V_L}{V_{in}}=\frac{j\omega L}{R+j\omega L}
\]

观察两个极限：

- 当 \(f=0\) 时，\(Z_L=0\)，电感两端电压接近 0，低频被抑制；
- 当频率升高时，\(|Z_L|\) 增大，电感分到的电压变大，高频通过。

因此它是高通滤波器。

截止频率定义在幅度下降到通带幅度的 \(1/\sqrt{2}\) 处，得到：

\[
f_c=\frac{R}{2\pi L}
\]

课件仿真例子使用：

\[
R=1000\ \Omega,\quad L=0.001\ H
\]

所以：

\[
f_c=\frac{1000}{2\pi\times0.001}\approx159.235\ kHz
\]

这里单位换算很重要：\(R/L\) 的单位是 \(1/s\)，还要除以 \(2\pi\) 才得到 Hz。

### 3.2 RL 低通：输出取电阻两端

同样的串联 R、L，如果输出取电阻两端：

\[
H_{LP}(j\omega)=\frac{V_R}{V_{in}}=\frac{R}{R+j\omega L}
\]

观察极限：

- 低频时电感阻抗很小，输入电压主要落在 R 上，低频通过；
- 高频时电感阻抗变大，更多电压落在 L 上，R 两端输出下降。

因此它是低通滤波器，截止频率仍为：

\[
f_c=\frac{R}{2\pi L}
\]

### 3.3 不要把截止频率当成“截止后立刻为零”

一阶 RL 滤波器在截止频率处的幅度是通带幅度的约 0.707 倍，也就是约 -3 dB。超过截止频率后，幅频曲线逐渐衰减，理想渐近斜率约为：

- 一阶低通：-20 dB/dec；
- 一阶高通：在低于截止频率的阻带中约 +20 dB/dec。

实际电路还会受到源阻抗、负载阻抗、线圈 DCR、寄生参数和仪器测量方式影响，所以实际截止点可能偏离简单公式。

## 四、RC 与 RL：为什么电源滤波常更关注 RL

### 4.1 RC 的优点与代价

RC 滤波器的典型低通结构是串联 R、并联 C。其优点是成本低、体积小、设计简单，适合小电流信号和轻负载电源。

但串联电阻会产生：

\[
V_{drop}=IR
\]

以及：

\[
P=I^2R
\]

当负载电流较大时，R 既造成直流压降，又持续发热。负载变化时，压降也会跟着变化。

### 4.2 RL 的优点与代价

RL 低通通常把电感串在电源路径中，再利用负载或电容形成滤波。真实电感的 DCR 可能只有 mΩ 级，因此：

- 直流压降较小；
- 直流功耗较低；
- 对大电流电源更有吸引力。

代价包括：

- 电感体积和成本通常高于电阻；
- 需要检查额定电流和饱和电流；
- 线圈有磁场，可能产生 EMI；
- 与电容、源阻抗和负载阻抗组合后可能振铃；
- 高频时不能只看 DCR，还要考虑寄生电容、磁芯损耗和自谐振。

### 4.3 RC、RL、LC 的选择思路

可以先按问题类型选择：

| 场景 | 常见优先方案 | 主要原因 |
|---|---|---|
| 小信号、低电流、成本敏感 | RC | 简单、便宜、阻尼天然较强 |
| 电源电流较大、不能接受较大压降 | RL 或 LC | 串联损耗可以较低 |
| 需要较强衰减、效率要求较高 | LC | 理想情况下无串联电阻损耗，但更容易谐振 |
| 需要抑制开关尖峰和振铃 | RC 或带阻尼的 LC | 阻尼有助于降低 Q 值 |

这里没有“任何场景都最好”的滤波器。滤波器是信号、源、负载和物理实现共同组成的系统。

## 五、T 型滤波器

课件给出的 T 型滤波器包含两个电感器和一个电容器，拓扑形状类似字母 T：

```text
输入 ── L1 ──┬── L2 ── 输出
              │
              C
              │
             地
```

它可以理解为“串联阻抗 + 并联旁路 + 串联阻抗”的组合：

- 低频或直流时，电感阻抗较小，电容不导通，目标信号可以通过；
- 高频时，两个电感呈现较大阻抗，同时电容为高频提供旁路路径；
- 两个串联电感和一个并联电容共同提高高频衰减能力。

### 5.1 T 型与 π 型的对比

T 型一般是“串联—并联—串联”；π 型一般是“并联—串联—并联”。在理想电路中，两者都可以构成较强的 LC 滤波网络，但实际表现依赖：

- 输入源阻抗；
- 输出负载阻抗；
- 电感 DCR 与饱和特性；
- 电容 ESR/ESL；
- PCB 走线和接地回路；
- 是否存在开关节点或快速边沿。

课件指出 T 型插入损耗性能与 π 型相似，并且不易出现“振铃”，可以用于开关电路。工程上应理解为“在特定源、负载和阻尼条件下可能更容易控制”，而不是 T 型天然绝不会振铃。任何 LC 网络都有储能元件，阻尼不足时都可能出现过冲和振铃。

### 5.2 为什么会振铃

电感储存磁场能量，电容储存电场能量。两者之间交换能量时，如果电阻损耗很小，系统 Q 值较高，就可能产生明显的谐振峰和时域振铃。

改进方法可能包括：

- 增加串联小电阻或 RC 阻尼支路；
- 选用具有合适 ESR 的电容；
- 调整电感、电容值及源/负载阻抗；
- 缩短高 di/dt 和高 dv/dt 回路；
- 用仿真和示波器确认实际波形。

阻尼电阻不能脱离拓扑直接拍一个固定数值。它要结合目标谐振频率、源阻抗、负载阻抗和器件损耗确定。

## 六、共模与差模：先分清干扰电流的方向

两根导线上的噪声，不能只按“频率高低”分类，还要看两根线上的电流或电压关系。

设两根线上的电压为 \(v_1\)、\(v_2\)，则：

### 6.1 共模分量

共模电压分量为：

\[
v_{CM}=\frac{v_1+v_2}{2}
\]

共模信号在两根线上相对于地大致同相、同方向变化。它的回流路径通常经过地、机壳、寄生电容或其他对地路径。

课件列举的共模干扰来源包括：

- 闪电、打火机放电等辐射或放电干扰；
- 不同接地点之间存在电位差；
- 电源线受到外部高频干扰耦合。

课件将共模干扰概括为高频、MHz 级别。这里应理解为典型场景，不是共模干扰的频率绝对都在 MHz；实际频率范围取决于干扰源、边沿速度、线缆长度和寄生参数。

### 6.2 差模分量

以第一根线为例，差模电压分量为：

\[
v_{DM}=\frac{v_1-v_2}{2}
\]

差模信号在两根线上大小相近、方向相反。它的电流主要在线与线之间形成回路，而不是以地为主要回流路径。

课件列举的差模干扰来源包括：

- 家庭大功率电器；
- 开关电源；
- 电动车充电器；
- 外部辐射在线缆上感应出的差模分量；
- 电路不平衡导致共模电流转换成差模干扰。

课件将差模干扰描述为通常幅度较小、频率较低。与共模一样，这属于常见经验，不能替代对具体波形和频谱的测量。

### 6.3 共模和差模不是互不相关

理想对称电路中，共模和差模可以清楚分解。但实际电路存在：

- 两条线阻抗不一致；
- 元件参数误差；
- 走线不对称；
- 对地寄生电容不一致；
- 连接器和负载不平衡。

因此，一部分共模干扰可能转换为差模干扰，反之也可能发生。EMC 设计中，对称性和回流路径非常重要。

## 七、用什么元件抑制共模和差模

### 7.1 共模扼流圈：对共模高阻，对差模尽量低阻

共模扼流圈通常把两根线同时穿过同一个磁芯，两个绕组匝数相同、绕向配合恰当。

对共模电流而言，两根线中的电流方向相同，磁通相互叠加，等效电感变大，因此对共模电流呈现较高阻抗。

对差模电流而言，两根线中的电流方向相反，磁通相互抵消，因此对差模电流的等效电感较小，正常信号或电源电流可以较容易通过。

这就是共模扼流圈“选择性抑制共模、尽量不影响差模”的物理基础。

需要注意：器件数据手册中的共模阻抗、差模阻抗、额定电流和频率曲线，才是选型依据。不能仅凭“有两个线圈”判断它在所有频率都理想有效。

### 7.2 X 电容：线与线之间，主要处理差模噪声

X 电容跨接在两根电源线之间：

```text
线 1 ─────────────
          │
          Cx
          │
线 2 ─────────────
```

它为线与线之间的高频差模噪声提供旁路路径。由于 X 电容接在两根线之间，失效模式和安规等级需要按跨线应用选择，不能用普通小信号电容随意替代。

### 7.3 Y 电容：线与地之间，主要处理共模噪声

Y 电容接在线与地、机壳或保护地之间，为共模高频噪声提供回流路径。

```text
线 ─────────────
       │
       Cy
       │
      地/机壳
```

Y 电容直接关联漏电流、触电安全和绝缘可靠性，必须使用对应安规等级的器件，并结合系统接地结构评估。Y 电容不是“容量越大越好”，因为容量增大会增加工频漏电流。

### 7.4 一个实用的判断顺序

遇到 EMI 问题时，可以按以下顺序判断：

1. 干扰是在线与线之间，还是在线与地之间？
2. 两根线上的噪声是同相，还是反相？
3. 高频电流的实际回路在哪里？
4. 需要 X 电容、Y 电容、共模扼流圈、差模电感，还是组合使用？
5. 器件的电压、电流、温升、安规、频率特性是否满足？
6. 加入滤波器后，是否引入了新的谐振或泄漏路径？

## 八、重要公式和快速记忆

| 内容 | 公式/结论 | 直觉 |
|---|---|---|
| 电感阻抗 | \(Z_L=j2\pi fL\) | 频率越高，越难通过 |
| 电容阻抗 | \(Z_C=1/(j2\pi fC)\) | 频率越高，越容易旁路 |
| RL 高通（输出取 L） | \(H=j\omega L/(R+j\omega L)\) | 低频电感近似短路，输出小 |
| RL 低通（输出取 R） | \(H=R/(R+j\omega L)\) | 高频电压更多落在电感上 |
| RL 截止频率 | \(f_c=R/(2\pi L)\) | 由 R 与 L 的阻抗相等决定 |
| 共模分量 | \(v_{CM}=(v_1+v_2)/2\) | 两线同相部分 |
| 差模分量 | \(v_{DM}=(v_1-v_2)/2\) | 两线反相部分 |
| 电阻损耗 | \(P=I^2R\) | 大电流下串联电阻很费电 |

记忆边界：

> 电感看电流变化，电容看电压变化；电感串联常用来“拦”，电容并联常用来“泄”。但最终效果必须结合源阻抗、负载阻抗和回流路径判断。

## 九、一个小例题：判断 RL 高通和低通

已知串联电路中：

\[
R=100\ \Omega,\quad L=100\ \mu H
\]

截止频率：

\[
f_c=\frac{100}{2\pi\times100\times10^{-6}}
\approx159.2\ kHz
\]

### 情况 A：输出取电感两端

- 频率远低于 159.2 kHz：\(|Z_L|\ll R\)，输出很小；
- 频率远高于 159.2 kHz：\(|Z_L|\gg R\)，输出接近输入。

结论：高通。

### 情况 B：输出取电阻两端

- 频率远低于 159.2 kHz：输出接近输入；
- 频率远高于 159.2 kHz：输出下降。

结论：低通。

## 十、工程中最容易犯的错误

### 错误 1：把“通直阻交”理解成电感对所有交流都阻碍

电感阻抗与频率成正比。低频交流可能仍然很容易通过，高频才更明显地被阻碍。

### 错误 2：只用理想公式选电感和电容

真实器件有 DCR、ESR、ESL、寄生电容、磁芯损耗和饱和。设计电源滤波时必须检查额定电流、饱和电流、温升和阻抗曲线。

### 错误 3：认为 LC 级数越高越好

级数增加通常能提高理想衰减，但也会增加谐振、启动过冲、控制环路相互作用和布局难度。开关电源尤其要检查控制环路稳定性。

### 错误 4：把共模和差模只按频率区分

共模/差模首先是电流或电压的关系与回路问题，不是简单的高频/低频标签。

### 错误 5：X、Y 电容可以互换

X 电容跨线，Y 电容对地，应用位置、失效风险和安规要求不同，不能互换。

### 错误 6：加了滤波器就默认 EMC 一定改善

滤波器本身也可能形成新的天线或谐振回路。器件位置、接地过孔、回流路径和连接器附近的布局，往往与元件数值同样重要。

## 十一、建议的学习与验证方法

### 仿真验证

用 SPICE 分别搭建：

1. RL 高通：输出取 L；
2. RL 低通：输出取 R；
3. 带负载的 T 型 LC；
4. 带源阻抗和负载阻抗的共模/差模等效电路。

每次只改变一个因素，观察：

- 截止频率；
- -3 dB 点；
- 通带压降；
- 谐振峰；
- 阻尼电阻变化后的 Q 值；
- 负载变化引起的滤波器变化。

### 示波器验证

不要只看输入和输出两根探头线，还要明确探头地夹的回路。高频测量中，长地线可能把测量结果变成“天线接收到的波形”。更可靠的做法是使用短地弹簧、合适的差分探头或专门的电流探头。

### EMC 现场判断

如果怀疑是共模问题，可以观察两根线相对于地的波形；如果怀疑是差模问题，可以观察两根线之间的差分波形。必要时使用 LISN、近场探头、频谱仪或电流钳进行频域和传导路径分析。

## 十二、课后练习

### 练习 1：RL 截止频率

串联 RL 电路中，\(R=10\ \Omega\)，\(L=10\ mH\)。求截止频率；如果输出取电阻两端，它是高通还是低通？

### 练习 2：功耗比较

某电源负载电流为 2 A。串联一个 0.2 Ω 电阻时，电阻上的压降和功耗分别是多少？如果改成 DCR 为 30 mΩ 的电感，直流压降和 DCR 损耗分别是多少？

### 练习 3：模态分解

若两根线上的干扰电压为 \(v_1=3V\)、\(v_2=1V\)，求共模分量和差模分量。

### 练习 4：器件选择

下列问题分别优先考虑什么：

- 两根电源线之间的高频噪声；
- 两根线同时相对机壳跳变的噪声；
- 两根电源线需要共同抑制共模电流，但不希望显著影响正常差模电流。

### 参考答案

1. \(f_c=R/(2\pi L)=10/(2\pi\times0.01)\approx159.2\ Hz\)。输出取 R，是低通。
2. 电阻压降 \(V=IR=0.4V\)，功耗 \(P=I^2R=0.8W\)。电感 DCR 压降为 \(2\times0.03=0.06V\)，DCR 损耗为 \(2^2\times0.03=0.12W\)。这只是直流损耗比较，未包含磁芯损耗和高频损耗。
3. \(v_{CM}=(3+1)/2=2V\)，\(v_{DM}=(3-1)/2=1V\)。对第二根线而言，差模分量为 -1 V。
4. 线间噪声优先考虑 X 电容或差模电感；线对地共模噪声优先考虑 Y 电容及合适的共模回路；共模扼流圈用于对共模高阻、对差模尽量低阻的场景。

## 十三、本课时的一句话总结

> RL 滤波器通过电感阻抗随频率升高而增大的特性实现高通或低通；RL 相比 RC 的主要工程优势是串联直流损耗可能更低；T 型 LC 网络能获得较强的滤波能力但必须关注阻尼；共模/差模滤波的核心不是背元件名称，而是先识别干扰电流的方向和回流路径。
