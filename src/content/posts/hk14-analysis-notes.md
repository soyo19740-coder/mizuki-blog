# PCB 设计学习笔记（基于 HK14 六层板分析）

> 整理日期：2026-09-07
> 参考实例：HK14 Main（6 层板，STM32 + FPGA/QSPI Flash + 16V 功率驱动）

---

## 1. 蛇形走线（等长匹配）

**现象**：S1 层（In2.Cu）上有大量弯弯曲曲的走线。

**本质**：蛇形走线（serpentine / meander），目的是**等长匹配（length matching）**。

**原理**：
- QSPI 是并行高速同步总线（4 根数据线 + 时钟 + 片选），数据在时钟沿采样
- 各线物理长度差太大 → 信号到达时间偏差（skew）→ 采样窗口变窄、时序违例
- 布局上天然较短的线绕成蛇形"补长"，让整组信号长度一致

**HK14 实例**：S1 层线段数最多的正是 QSPI 组——IO3（69 段）、IO2（55）、SCK（44）、FPGA_CS（33）等；IO1 只有 9 段说明它路径天然短，其他线在给它"陪跑"或它本身位置近。

**最好的等长是不需要等长**：布局时让高速器件靠近，走线短到无需绕线。

## 2. 六层板叠层与各层用途

**经典叠层**：`Sig / GND / S1 / S2 / PWR / Sig`（HK14 即此方案）

| 层 | 名称 | 用途 |
|---|---|---|
| L1 | 顶层 F.Cu | 元件焊盘、扇出、短引出线；不适合长距离高速线（阻抗受阻焊影响、对外辐射） |
| L2 | GND（In1） | **完整地平面**，不走线、不被过孔切碎；是 L1/L3 的回流参考，决定整板 EMI |
| L3 | S1（In2） | **最优质走线层**：紧贴完整地平面，阻抗最可控、屏蔽最好。放高速/时序敏感信号（QSPI、USB、时钟）和等长组 |
| L4 | S2（In3) | 次要信号层（UART、I2C、GPIO 控制线）；参考电源平面，回流不如 S1 干净；与 S1 正交走线减少串扰 |
| L5 | PWR（In4） | 电源平面分割（3.3V、16V 等），低阻抗配电；注意别让 S2 高速线跨分割缝 |
| L6 | 底层 B.Cu | 背面元件、去耦电容、测试点、低速补充走线 |

**一句话**：高速关键信号走 S1，普通信号走 S2 和表层，地和电源各占一整层保持完整。

## 3. 过孔的作用与数量

**HK14 数据**：全板约 433 个过孔，其中 GND 占 199 个，+3V3 占 21，BATT/+16V 各 10，其余信号每网络 2~4 个。

**三类过孔**：

1. **GND 缝合孔（stitching vias）**——数量最多
   - 把各层地铜低阻抗连成整体
   - 给换层信号提供回流路径（信号换参考平面时，回流电流需就近的 GND 孔跨层）
   - 板边一圈形成屏蔽墙，抑制边缘辐射
   - 功率器件焊盘下的孔阵列兼作散热
2. **电源过孔**——连表层元件到电源平面；大电流用多孔并联（单个 0.3mm 孔载流有限）
3. **信号换层孔**——布线必需，无冗余

**需要这么多吗？**：需要。GND 缝合孔几乎零成本（机械钻孔数量对板价影响可忽略），收益是 EMC、地稳定性、散热。惯例按 5~10mm（或 λ/20）网格撒孔。

**关键不是数量而是位置**：
- 高速信号换层孔旁 1~2mm 内要有伴随 GND 回流孔
- 缝合孔别把地平面切碎，别在高速线正下方排成一条缝

## 4. 新设计六层板的优先级清单

1. **叠层结构（最优先）**：定叠层方案，与板厂确认介质厚度/铜厚/板材，算出 50Ω 单端、90Ω USB 差分的线宽线距，**开始布线前**设进规则
2. **平面规划**：L2 地完整；L5 电源分割想清楚，铜皮盖住对应负载区，S2 信号不跨缝
3. **布局分区**：功率区与敏感区（ADC、射频、晶振）物理隔开；电流路径顺流而下；高速器件就近摆放
4. **高速布线规则**：关键信号走 S1、参考完整地；换层最少化 + 伴随回流孔；总线等长、差分对等长/阻抗控制
5. **电源完整性**：每个电源脚就近去耦（100nF + 局部 1~10µF），环路面积最小；大电流多孔+宽铜
6. **地缝合与 EMC 收尾**：表层铺地、网格撒缝合孔、板边围一圈
7. **DFM**：过孔/线宽用板厂常规工艺不贴极限；测试点、Mark 点、工艺边、丝印

**前三项在画第一根线之前定死——它们决定上限，后面是兑现上限。**

## 5. PCB 需要考虑的参数（六大类）

1. **板材与叠层**：板材类型（FR-4 / 高 Tg / 低损耗 / 铝基）、Dk（FR-4 约 4.2~4.6）、Df、Tg（无铅焊 ≥150℃）、层数、板厚（常规 1.6mm）、铜厚（常规 1oz，大电流 2oz+）
2. **布线工艺**：最小线宽/线距（常规 6/6mil）、线宽载流（1oz 铜 1mm 宽约 1~2A @10℃温升）、阻抗控制、等长公差
3. **过孔与钻孔**：通孔/盲埋孔/HDI 微孔、最小孔径 0.2~0.3mm、深宽比 ≤10:1、塞孔/VIPPO（BGA 下）
4. **电气性能**：工作电压与爬电距离/电气间隙（220V ≥2.5mm）、绝缘耐压、载流、EMC 策略
5. **表面处理与阻焊**：HASL（便宜）/ ENIG（平整、适合 BGA）/ OSP；阻焊颜色；金手指镀硬金
6. **结构与 DFM/DFT**：外形公差、板边禁布 ≥0.3~0.5mm、拼板（V-cut/邮票孔、工艺边 ≥3~5mm）、元件间距、测试点、Mark 点、散热设计

**顺序**：电气需求定叠层/板材/阻抗 → 板厂工艺定线宽/过孔 → DFM 检查表收尾。

## 6. 高速板 vs 低速板

**本质区别**：是否需要把走线当**传输线**对待。

**判断标准**：看**边沿速度（tr）**而非时钟频率。走线长度 > 临界长度（≈ tr × 传播速度 / 6）即为高速。
- 1MHz I2C（边沿几百 ns）走 20cm 仍是低速
- 1kHz GPIO 若边沿 1ns、走线长，照样振铃，是高速

| 方面 | 低速板 | 高速板 |
|---|---|---|
| 走线模型 | 导线，通了就行 | 传输线：阻抗、延时、反射 |
| 阻抗控制 | 不需要 | 必须，与板厂联算 |
| 回流路径 | 不关心 | 核心问题：完整参考平面 + 回流孔 |
| 长度匹配 | 无 | 等长/差分对内等长 |
| 端接 | 不需要 | 可能需要源端/终端端接 |
| 拓扑 | 随意分叉 | 点对点/菊花链，禁长桩线 |
| 叠层 | 双面板够用 | 多层 + 专用地平面 |
| 过孔 | 连接手段 | 阻抗不连续点，少打，必要时背钻 |
| 串扰 | 不管 | 3W 规则、层间正交 |
| 失败模式 | 连错/短路（万用表可查） | DRC 全过但"时好时坏"、EMC 不过 |

现代芯片 IO 边沿普遍 1~2ns 以内，"纯低速板"越来越少。

## 7. GND 引脚接地方法

**核心原则：就近、低阻抗、短回路**

1. 多层板：每个 GND 脚**就近打孔直下地平面**；不要多脚串线共用一孔（公共阻抗耦合）
2. 过孔紧贴焊盘（0.3~0.5mm 内）；去耦电容 GND 环路面积最小化
3. 焊盘连接方式：功率/散热焊盘直连；普通小元件热焊盘
4. 大电流/QFN 底部 EP：过孔阵列（接地 + 散热）
5. 模拟地：不建议物理分割，靠**布局分区**让回流自然分开
6. 禁忌：靠铺铜"顺便"连地、地线绕远路、单点细线接地

**HK14 评价**：
- ✅ GND zone 覆盖全 6 层 + In1 专用地平面 + 199 个缝合孔 → 立体低阻抗地网络
- ✅ 热焊盘参数标准（gap 0.5 / bridge 0.5）；QFN EP 用直连，区分正确
- ✅ 孤岛移除开启
- ⚠️ 需目检：In1 地平面是否被过孔反焊盘切缝（尤其 QSPI 下方）；高速换层孔旁是否有伴随回流孔

## 8. 铺铜注意事项 & 实心连接 vs 热焊盘

### 两种焊盘-铜皮连接方式（zone_connect）

**实心连接（Solid，直连）**：焊盘与铜皮完全融合
- 优点：阻抗最低、载流最大、散热最好
- 缺点：焊接时热量被铜皮抽走 → 虚焊、冷焊、小元件立碑；难返修
- 用途：功率器件、散热焊盘（QFN EP、MOS 漏极）

**热焊盘（Thermal Relief，花焊盘）**：隔离环 + 4 根细辐条
- 优点：限制热传导，可焊性好
- 缺点：阻抗和载流不如直连
- 用途：普通元件的 GND/电源脚（默认选择）

### 铺铜八条注意事项

1. 铜皮必须接明确网络，绝不留浮铜
2. 开孤岛移除；避免细长条/尖角铜（设最小铜宽，如 0.25mm）
3. 铺完要缝合：表层地铜按 5~10mm 网格打 GND 孔连到地平面
4. 间距留余量（0.2~0.3mm 常规）；高压区按爬电加大；板边禁布 ≥0.3~0.5mm
5. 铜皮优先级：小的局部铜皮（功率网络）优先级高，大 GND 铜皮优先级低
6. 铺铜不能代替走线：大电流路径主动规划，铺完高亮网络检查最窄处
7. **发板前重新填充所有铜皮（KiCad 快捷键 B）再跑 DRC**——用旧填充出 Gerber 是经典事故
8. 大铜皮两面对称防翘曲；波峰焊面大铜可考虑网格铺铜

### HK14 铺铜配置实例

| 铺铜 | 层 | 优先级 | 说明 |
|---|---|---|---|
| GND 全局 | 全 6 层 | 默认（最低） | 热焊盘 0.5/0.5，最小铜宽/间距 0.25mm，孤岛移除开 |
| BATT 局部 ×2 | F/B 两层 与 全 6 层 | 1 / 2 | 铜皮承载电池大电流，高优先级让 GND 避让 |
| 直连覆盖 | — | — | 仅 2 处：QFN-48 和 QFN-16 的底部散热焊盘（EP） |

**评价**：GND 全局铺 + 功率网络局部高优先级铺 + 散热焊盘精准直连——有针对性的良好实践。
可留意：QFN-48（0.4mm 间距）的小焊盘辐条可能连不满，需高亮 GND 网络确认连通；全层 BATT 铜皮是否在 In1 地平面上开了不必要的口。
