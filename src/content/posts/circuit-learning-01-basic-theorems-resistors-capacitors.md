# 第一课时：基本定理、电阻、电容等

> 学习来源：`D:\Archive_afeng\硬件学习课件\第一课时-基本定理、电阻、电容等(1).pptx`（30 页）  
> 本笔记按“基本理论 → 电阻 → 电容 → 规格书与选型”整理。课件中部分页面是图片或规格书截图，以下内容结合页面文字和渲染图归纳。

## 一、课程定位

课件属于“实用电路设计基础培训”的第一课时，目录还预告了后续的二极管、三极管/MOS 管、电源、驱动、运算放大器、ADC 和综合设计等内容。本课时实际重点是：

1. 掌握分析线性电路的几个基本定理；
2. 认识导线和电阻的规格、封装、编码及功率限制；
3. 理解电容的储能、去耦、耦合、软启动和充放电；
4. 学会从电容材质、封装、额定电压、容差、ESR/ESL 等角度初步选型。

## 二、基础电路定理

### 1. 基尔霍夫电流定律 KCL

对任一节点，流入节点的电流代数和等于流出节点的电流代数和：

\[
\sum i=0
\]

常用理解：节点不能凭空产生或消失电荷。列节点方程、分析并联支路和电源回路时经常使用 KCL。

### 2. 基尔霍夫电压定律 KVL

沿任意闭合回路，各元件电压的代数和为零：

\[
\sum v=0
\]

常用理解：绕回路走一圈，电压升高与电压下降相互平衡。分析串联电路、回路电流和电源压降时经常使用 KVL。

### 3. 叠加定理

对于线性双边网络，多个独立源共同作用时，任一支路的电压或电流响应，等于各独立源单独作用时响应的代数和。

使用步骤：

1. 只保留一个独立源；
2. 其他独立源置零：理想电压源置零等效为短路，理想电流源置零等效为开路；
3. 计算该独立源产生的响应；
4. 对每个独立源重复计算并代数相加。

注意：叠加定理直接叠加的是电压或电流，不能直接叠加功率；功率需要在总电压/总电流下重新计算。受控源通常不能简单关闭，应按具体电路保留。

### 4. 戴维南定理

从两个端口看，一个线性网络可以等效为：

```text
理想电压源 Vth + 串联等效电阻 Rth
```

适合分析不同负载接入同一网络后的端电压、负载电流和功率。

### 5. 诺顿定理

从两个端口看，同一线性网络也可以等效为：

```text
理想电流源 In + 并联等效电阻 Rn
```

两种等效可以相互转换：

\[
V_{th}=I_N R_{th},\qquad R_{th}=R_N
\]

### 6. 奈奎斯特采样定理

对最高频率为 `fmax` 的带限信号，采样频率应满足：

\[
f_s > 2f_{max}
\]

否则会发生混叠，高频成分折叠到低频，采样后无法仅靠数字处理恢复原信号。

工程上通常还会在 ADC 前增加抗混叠低通滤波器，并留出一定余量，而不是只按 `2fmax` 临界取值。

## 三、导线与线规

课件介绍了常见线规体系：

- AWG：美国线规；
- GB：中国线规；
- SWG：英国线规；
- DIE：德国线规；
- IEG：国际电工线规。

导线选型不能只看线径，还要结合允许电流、温升、绝缘耐压、布线长度、压降、机械强度和环境条件。不同线规体系的数字不能直接混用，需确认标准和单位。

## 四、电阻

### 1. 基本关系与作用

欧姆定律：

\[
U=IR
\]

功率关系：

\[
P=UI=I^2R=\frac{U^2}{R}
\]

电阻的主要作用包括限流、分压、偏置、设定增益、采样电流、终端匹配、放电和耗能。

### 2. 常见类型

课件展示了：

- 金属膜电阻；
- 碳膜电阻；
- 水泥电阻；
- 绕线电阻；
- 贴片电阻；
- 贴片网络电阻。

贴片网络电阻把多个电阻集成在一个封装内，适合多路上拉、限流或匹配，但要确认内部连接方式（独立、公共端或阵列结构）。

### 3. 封装尺寸

常见贴片电阻封装有 `01005、0201、0402、0603、0805、1206、1210、1218、2010、2512` 等。

例如 `0402` 通常表示约 `0.04 × 0.02 inch`，约为 `1.0 × 0.5 mm`。封装越小，通常可承受的功率和电压越低，但具体值必须以制造商规格书为准。

### 4. E 系列标称阻值

电阻标称值采用 E 系列，常见有 `E6、E12、E24、E48、E96、E192`。课件给出的典型对应关系是：

| 系列 | 典型精度 |
| --- | --- |
| E6 | 20% |
| E12 | 10% |
| E24 | 5% |
| E48 | 2% |
| E96 | 1% |
| E192 | 0.5% |

E 系列本质上是在每个十倍区间内按近似等比规律分布阻值，精度越高，阻值档位越密。

### 5. 电阻丝印

常见规则：

- 三位数代码通常用于 `5%` 电阻：前两位为有效数字，最后一位为倍率；
- 四位数代码通常用于 `1%` 电阻：前三位为有效数字，最后一位为倍率；
- 例如 `1003 = 100 × 10^3 Ω = 100 kΩ`，常见于四位数表示。

小阻值常用 `R` 代替小数点，例如 `4R7 = 4.7 Ω`、`R22 = 0.22 Ω`。

精密电阻容差字母示例：

| 字母 | 容差 |
| --- | --- |
| T | ±0.01% |
| A | ±0.05% |
| B | ±0.1% |
| D | ±0.5% |
| F | ±1% |
| J | ±5% |
| K | ±10% |

### 6. 贴片电阻型号命名

课件示例：`RS-05K102JT`、`RS-05K1002FT`。其中可能包含系列/电阻标识、额定功率、尺寸、温度系数、阻值代码、精度和编带包装等信息。

实际采购时不能只凭型号字符猜参数，应对照对应厂家的命名规则和完整规格书。

### 7. 额定功率与额定电压

电阻需同时满足功率和电压限制：

\[
P=I^2R=\frac{U^2}{R}
\]

即使计算功率没有超标，也可能因为电阻两端电压超过额定电压而失效。封装越小，额定功率和额定电压一般越低；多个品牌的同尺寸参数可能不同。

设计时建议留出降额，参考制造商的负荷曲线，而不是长期工作在额定极限。

### 8. 温度系数和温漂

温度系数常用 `ppm/°C` 表示。近似计算：

\[
\frac{\Delta R}{R}=\text{温度变化}\times\text{温度系数}
\]

课件例子：`100 ppm/°C` 的电阻从 `20°C` 升到 `100°C`，温差为 `80°C`：

\[
80\times100/1{,}000{,}000=0.8\%
\]

精密测量、采样和基准电路要重点关注温漂、长期稳定性和自热误差。

### 9. 0 Ω 电阻

0 Ω 电阻并非理想导线。课件指出其实际最大阻值可能为 `10 mΩ、20 mΩ、50 mΩ` 等，并且不同厂家、不同封装的过流能力不同。

常见用途：

- PCB 配置选项；
- 便于调试时断开或串入仪表；
- 替代跳线；
- 预留不同电源/信号路径。

选型仍需检查实际阻值、额定电流、额定功率、脉冲能力和温升。

## 五、电容

### 1. 基本关系

电容的基本关系：

\[
i_C=C\frac{dv_C}{dt}
\]

含义是：电容阻碍两端电压突变，电压变化越快，产生的电流越大。

储存能量：

\[
E_C=\frac{1}{2}CV^2
\]

电容阻抗：

\[
Z_C=\frac{1}{j\omega C},\qquad |X_C|=\frac{1}{2\pi fC}
\]

频率越高，理想电容阻抗越低；直流稳态时，理想电容相当于开路，但充电瞬间和变化信号中会有电流。

### 2. 电容的主要作用

#### 旁路与去耦

把电源或信号中的高频噪声旁路到地，并在负载瞬态需要电流时提供短时能量。去耦电容通常应靠近芯片电源引脚，回路面积越小越有利于高频效果。

#### 储能

超级电容专门用于较大能量储存；普通电容也可在短时间内储能、放电，用于负载瞬态支撑和纹波降低。

#### 耦合与隔离

串联电容可以隔离直流偏置，同时让交流变化信号通过，常见于级间耦合、音频和通信信号。

#### 软启动

利用电容两端电压不能突变的特性，使控制节点或电源输出缓慢上升，降低启动瞬间的冲击。

#### RC 定时与波形处理

电容和电阻组合可以构成积分、微分、定时、自举和滤波电路。实际效果取决于时间常数：

\[
\tau=RC
\]

### 3. 充电与放电

在简单 RC 电路中，时间常数为 `τ = RC`：

- 充电约经过 `1τ` 达到最终值的 `63.2%`；
- 约经过 `5τ` 基本充满；
- 放电约经过 `1τ` 降到初始值的 `36.8%`；
- 约经过 `5τ` 基本放完。

电容电压不能瞬间跳变，但电容电流可以在切换瞬间很大，因此需要考虑限流、电阻、开关器件和后级耐受能力。

### 4. 方波与傅里叶分解

方波可以表示为基波及奇次谐波的叠加。课件用多个正弦分量叠加展示方波逐渐逼近的过程，并联系电容的去耦功能：

- 方波边沿包含较多高频成分；
- 高频去耦电容能够为瞬态电流提供路径；
- 电容、ESR、ESL 和布线寄生共同决定实际边沿与噪声效果。

### 5. 实际电容的 ESR 与 ESL

理想电容没有功率损耗、没有寄生电感；实际电容可用串联等效模型表示：

```text
ESL + 理想电容 C + ESR
```

- **ESR**：Equivalent Series Resistance，等效串联电阻。电流流过 ESR 会产生功耗和发热：

\[
P_{ESR}=I_{RMS}^2\times ESR
\]

- **ESL**：Equivalent Series Inductance，等效串联电感。高频下 ESL 的感抗变大，会限制电容的去耦效果。

因此，电容并不是频率越高阻抗永远越低。到达自谐振频率附近时阻抗最低，超过该频率后，ESL 可能使它呈现感性。

## 六、电容分类

### 1. 按原理或结构

- 无极性可变电容；
- 无极性固定电容；
- 有极性电容，如铝电解、钽电容等。

有极性电容接反可能失效甚至损坏，设计时必须确认极性、额定电压和纹波电流。

### 2. 按介质材料

课件列出：

- CBB（聚丙烯）电容；
- 涤纶电容；
- 瓷片电容；
- 云母电容；
- 独石/多层陶瓷电容；
- 电解电容；
- 钽电容。

不同材料在容量范围、稳定性、损耗、耐压、体积、成本和频率特性上差异很大，不能只按“容量相同”替换。

### 3. 钽电容注意事项

课件强调钽电容本身寄生电感相对很小，但失效方式可能与电压、电流和发热有关。实际使用时应关注：

- 额定电压降额；
- 浪涌电流；
- 纹波电流与温升；
- 反向电压；
- 短路失效风险及系统保护。

## 七、陶瓷电容介质：C0G/NPO、X7R、Y5V、Z5U

| 介质 | 典型特点 | 常见用途/注意事项 |
| --- | --- | --- |
| C0G/NPO | 介电常数较低，容量稳定，温度、电压和时间影响小，损耗低 | 高频、精密、定时、谐振、稳定信号 |
| X7R | 介质稳定性中等，容量受温度和直流偏压影响 | 通用去耦、旁路、耦合；需看实际偏压下容量 |
| Y5V | 介电常数高，体积小、容量大，但温度和电压稳定性较差 | 对容量和损耗要求不高的场合 |
| Z5U | 容量密度高，但温度、老化和工作条件影响更明显 | 低成本、对稳定性要求不高的场合 |

课件指出，Z5U 的老化率可能较大；具体参数必须以厂商数据为准。对于 MLCC，标称容量不等于所有工作条件下的有效容量，尤其要注意直流偏压降容。

## 八、电容规格书与型号读取

### 1. 常见选型字段

电容选型至少要核对：

- 封装尺寸；
- 标称容量；
- 容量容差；
- 额定电压；
- 温度特性/介质；
- ESR；
- ESL 或阻抗曲线；
- 纹波电流；
- 工作温度；
- 极性；
- 品牌、系列和可靠性等级。

### 2. Murata GRM 型号示例

课件用 `GRM` 系列型号说明编码通常包含：

```text
系列/产品代码 - 尺寸 - 厚度 - 温度特性 - 额定电压 - 标称容量 - 容差 - 控制代码 - 包装代码
```

例如页面中的示例把尺寸、温度特性、额定电压、容量、容差、厂家控制码和包装码分段表示。不同品牌命名规则不完全相同，应以该品牌的选型手册为准。

### 3. 选型思路

可以按以下顺序筛选：

1. 先确定用途：去耦、滤波、耦合、定时、储能或谐振；
2. 确定有效容量和工作频率；
3. 选择足够的额定电压并留降额；
4. 根据温度、直流偏压、容差和老化确认实际容量；
5. 对高频/大纹波场景检查 ESR、ESL、阻抗和纹波电流；
6. 确认封装、焊盘、极性、寿命和供应情况；
7. 用规格书曲线和实测波形验证，而不是只看标称容量。

## 九、课件内容中的关键工程判断

### 1. 理想模型只是第一步

理想电阻、电容可以帮助建立公式和直觉，但实际元件具有容差、温漂、自热、寄生参数和频率依赖。规格书参数和应用曲线决定了它在真实电路中的表现。

### 2. 封装会影响电气性能

封装尺寸不仅影响能承受的功率、耐压和机械可靠性，也影响寄生电感、散热和高频性能。相同容量、相同额定电压的电容，封装和介质不同，实际去耦效果可能差异很大。

### 3. 元件参数要结合工作条件看

电阻要结合电流、电压、功率、温度和脉冲；电容要结合直流偏压、频率、纹波、温度、极性和寿命。任何“这个值一样就能替换”的判断都需要回到规格书。

## 十、复习抓手

1. **KCL** 看节点电流，**KVL** 看闭合回路电压。
2. 叠加定理用于线性电路；电压源置零为短路，电流源置零为开路。
3. 戴维南是“电压源串联电阻”，诺顿是“电流源并联电阻”。
4. 电阻先看 `U=IR` 和 `P=I²R`，再看额定电压、功率和温漂。
5. 电容先记住 `i=C·dv/dt`：它抗电压突变、能储能、可隔直通交。
6. 去耦效果不能只看容量，还要看 ESR、ESL、封装、布局和工作频率。
7. 读型号只能完成初筛，最终必须回到制造商规格书和降额曲线。
