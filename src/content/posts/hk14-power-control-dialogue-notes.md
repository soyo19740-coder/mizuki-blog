# HK14 与电源控制电路：对话知识笔记

> 本笔记整理了本次对话中关于 KiCad 改板、PWR.CU 电源层、GND 接地、MOSFET 控制、Boost 升压和滤波器的分析结论。
>
> 项目路径：`D:\project_afeng\hk14-main`。涉及 PCB 的判断以当时读取到的 `HK14 Main.kicad_pcb` 为依据；截图观察不能替代 KiCad DRC、原理图一致性检查和实物测量。

## 1. PCB 上边缘下移 0.8 mm

原上边缘约为 `Y=35.976668 mm`，下移 `0.8 mm` 后新边缘约为：

```text
Y=36.776668 mm
```

KiCad 中本工程的 Y 坐标向下增加，因此 `Y` 小于新边缘的对象会进入切除区域。

### 受影响对象

- 连接器：`J2`、`J4`，需要优先按机械结构处理，不能像普通电阻电容一样简单移动。
- 小器件：`C40`、`C37`、`D11`、`D12`，存在焊盘或封装区域贴近新板边的问题。
- 铜箔：J4 附近 GND 走线、`In2.Cu` 走线、`In4.Cu/PWR.CU` 上的 `BATT` 主干。
- 过孔：原分析发现多个过孔中心位于新板边以上，必须逐个确认网络并下移、删除或重建。

### 推荐修改顺序

```text
确定机械边界
→ 确认 J2/J4 的外壳、插拔和固定脚约束
→ 移动连接器及相邻器件
→ 重布 BATT、GND、+3V3 等电源和信号线
→ 调整过孔
→ 检查板边间距、未连接和 DRC
```

板边不是铜箔允许到达的位置。建议在新 Edge.Cuts 内侧额外预留约 `0.25~0.30 mm` 的安全参考线，具体数值以板厂能力和项目规则为准。

## 2. PWR.CU 改版参考

本工程层表中，用户名称 `PWR.Cu` 对应内部层 `In4.Cu`。当前该层由多个网络组成，主要包括：

- `BATT`
- `+3V3`
- `+1V2`
- 少量其他电源/信号网络

不能把 PWR.CU 当成一个可以整体平移的单一网络。

### BATT

当前 `BATT` 有约 `0.8 mm` 宽的主干，靠近原上边缘。切边后必须把主干、斜向过渡和换层过孔一起后退，否则铜带边缘仍会越过 Edge.Cuts。不要只把线头截短；应保持载流宽度，并重新连接两侧过孔和负载。

### +3V3 与 +1V2

- `+3V3` 可采用“主干 + 分支 + 近端去耦”的结构，重点检查主干到板边的铜边距离。
- `+1V2` 相对远离新板边时可以尽量少改，避免扩大改版范围。
- 去耦电容要保持靠近负载，不能为了避边而大幅拉长电源回路。

### 过孔

- `BATT` 换层过孔不能随意删除，必要时需要下移或增加并联过孔。
- 普通 GND 缝合过孔可以在安全区域重建，但要保留回流路径。
- 普通信号过孔要确认网络和换层功能后再移动。

## 3. J5 的 GND 接地分析

J5 是 `CS_Library:CONN_FPC_0.5mm_32p_Double_sided`，封装中标记为 GND 的普通焊盘包括 `3、4、9、11、28`，另有两个 `SH` 屏蔽焊盘。

当时从 PCB 文件看到：焊盘的网络属性是 `GND`，但未能从附近显式走线确认所有焊盘均已可靠接入 GND 铜路或过孔；工程中也不能仅凭颜色假定存在完整 GND 覆铜区。因此应区分：

```text
网络名标记为 GND ≠ 已经完成物理接地验证
```

建议在 KiCad 中逐个高亮 J5 的 GND 焊盘，检查是否有飞线，并切换 `F.Cu`、`B.Cu`、`In4.Cu/PWR.CU` 等层确认实际连接。推荐使用“局部 GND 汇流 + 靠近连接器的多个 GND 过孔”，SH 焊盘使用短而宽的屏蔽接地路径。

## 4. DRC 警告的含义

截图中的警告主要有两类：

### `CS_Library` 不在当前配置中

J1~J5 的封装已经嵌入 PCB，但当前 `fp-lib-table` 未配置 `CS_Library`，或路径不可用。它通常不会立即使现有 PCB 图形消失，但会影响从原理图更新 PCB、重新载入封装和跨电脑维护。应确认 `CS_Library.pretty` 和 `fp-lib-table` 路径。

### U9 封装副本不匹配

U9 的 PCB 封装与 `Package_TO_SOT_SMD` 库中同名 `SOT-363_SC-70-6` 不一致，可能是旧版本或本地修改。不要直接盲目执行全板“从库更新封装”，应先核对焊盘编号、尺寸、间距、方向和实际器件数据手册。

截图同时显示“未连接项 0”，这只说明该次检查未发现 KiCad 报告的飞线，不能单独证明 J5 所有 GND 焊盘、电源层和机械边界都已验证通过。原理图一致性检查当时也未运行。

## 5. 22 Ω + 100 pF 数据线网络

CD4504 输出侧每一路采用：

```text
芯片输出 ── 22 Ω 串联电阻 ── 数据线
                              │
                            100 pF
                              │
                             GND
```

这不是电阻和电容串联，而是串联 R、对地并联 C，构成边沿整形网络。

- `22 Ω`：限制瞬态充放电电流，抑制过冲、下冲和振铃，改善 EMI。
- `100 pF`：旁路高频尖峰、减慢边沿、滤除窄脉冲噪声。

按标称值：

```text
τ=RC=22 Ω×100 pF=2.2 ns
f-3dB≈1/(2πRC)≈72 MHz
10%~90% 上升时间≈2.2RC≈4.8 ns
```

这是理论一阶 RC 估算，实际还受芯片输出阻抗、负载电容、走线和连接器寄生参数影响。数据速率较高时，应以接收端示波器波形确认 100 pF 是否过大。

## 6. BATT 到 16 V 的 Boost 电路

整体链路为：

```text
BATT → Q3/Q2 输入开关 → 输入去耦 → MT3608 + L1 + D9 → +16V
                                                     ↓
                                  R37=0.1 Ω 电流检测
                                                     ↓
                                  多组输出电容与负载
```

- `L1` 是 Boost 的储能电感，不只是普通滤波电感。
- `D9` 是整流肖特基二极管。
- D9 后的电容负责降低升压开关纹波、支撑负载瞬态。
- R37 的首要作用是电流检测，附带少量隔离和阻尼。

R37 前后若分别有电容组，拓扑上可称为带电流检测电阻的 `C-R-C π 型` 后级结构：

```text
C前 ── R37(0.1 Ω) ── C后
```

但 `0.1 Ω` 很小，不能把它当作专门设计的阻尼电阻。其压降和功耗为：

```text
V=I×0.1 Ω
P=I²×0.1 Ω
```

需要检查额定功率、Kelvin 采样、负载压降和控制环路稳定性。

## 7. Q2：2N7002 的工作机制

`2N7002` 是 N 沟道增强型 MOSFET，三个电极为：

```text
G=Gate，栅极：控制端
D=Drain，漏极：电流流出端
S=Source，源极：来源端
```

栅极与沟道绝缘，直流栅极电流很小。真正控制导通的是：

```text
VGS=VG−VS
```

当 `VGS` 足够正时，栅极电场在 D、S 之间形成 N 型导电沟道，D-S 电阻降低；当 `VGS≈0` 时，沟道消失，器件关闭。`VGS(th)` 只是出现小电流的阈值，不等于已经充分导通，实际还要看指定栅压下的 `RDS(on)`。

在当前电路中：

```text
Q2 G → EN_16V_P
Q2 S → GND
Q2 D → Q3 栅极
```

因此 Q2 是一个受 EN 控制的开漏下拉开关，不直接给 16 V 负载供电。

## 8. Q3：P 沟道高边开关

截图中的 Q3 型号为 `P-CMN5P04M`，从原理图接法判断：

```text
Pin 1：G，栅极，接 Q2 控制节点
Pin 2：S，源极，接 BATT
Pin 3：D，漏极，接后级升压电路
```

在该具体符号中可记为：

```text
左 2 脚=S，下面 1 脚=G，右 3 脚=D
```

Q3 的导通条件为 `VGS` 足够负：

```text
Q2 导通 → Q3 G≈0 V，Q3 S≈BATT
→ VGS(Q3)=VG−VS<0
→ Q3 导通
→ BATT 送到后级
```

Q2 关闭时，必须由 `R94=10 kΩ` 把 Q3 栅极拉回源极/BATT：

```text
Q3 G≈Q3 S≈BATT
→ VGS≈0 V
→ Q3 关闭
```

如果没有这个栅极—源极上拉，Q3 栅极会悬空，可能保持低电压而误导通。还要检查 Q3 最大 `VGS`，避免 Q2 将栅极直接拉地时超过额定值。

## 9. N 沟道与 P 沟道记忆方法

最重要的是先算 `VGS`，不要只凭元件在图上的上下位置。

```text
N-MOS：VGS 为正，栅极高于源极时导通
P-MOS：VGS 为负，栅极低于源极时导通
```

常见接法口诀：

```text
N 管下，S 接地；G 高导通
P 管上，S 接电；G 低导通
```

三个极的记忆：

```text
G=Gate=闸门，负责控制
S=Source=来源
D=Drain=流出
```

常见接法不是绝对规则。更换 MOSFET 时必须重新查具体型号的数据手册，确认引脚编号、体二极管方向、最大 `VDS/VGS` 和指定栅压下的 `RDS(on)`。

## 10. 最终验证边界

以下内容不能仅凭截图或源文件静态分析确认：

- 真实板厂制造能力和最终板边孔距；
- 连接器与外壳、FPC 插拔的机械干涉；
- 实际焊接质量和温升；
- Boost 输出纹波、负载瞬态和环路稳定性；
- J5 GND 的真实低阻抗回路，除非在 KiCad 中逐网高亮并运行检查；
- 数据线 RC 网络在真实速率下的波形。

建议最终执行：

```text
PCB 与原理图一致性检查
→ Refill Zones
→ DRC
→ Unconnected Items 检查
→ 3D 机械检查
→ 示波器检查电源和数据波形
```
